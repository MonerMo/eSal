eSal Backend Changes - Swift Integration Brief

2026-07-17 · covers every endpoint added or changed in this session
Summary: one field (transactionDate) was added across six existing endpoints - additive, nothing breaks if ignored. One existing endpoint's data went from hardcoded mock to real (/dashboard's smartOffers) - same shape, but now can return an empty array. Two brand-new endpoints exist but are backend-only for now - no UI needed yet, included here for reference.

1. Field added: transactionDate

Every affected endpoint gained one new field in its response. No other field changed. Type is always the same:

transactionDate: string | null   // ISO 8601 date-time, e.g. "2026-07-15T14:32:00.000Z"
                                  // null if the receipt's date wasn't printed/detected
